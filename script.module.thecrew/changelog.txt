[COLOR lime]NEW FEATURE - TV EVENING:[/COLOR]
[COLOR orchid]*** Experience a whole new way to binge-watch your favorite shows! ***[/COLOR]

TV Evening is an automatic playlist mode that transforms your TV show watching experience:
- Beautiful fullscreen overlay with show backdrop appears during episode scraping
- Episode information and cast photos displayed elegantly during transitions
- Smart countdown appears at 92% of episode completion (not during credits!)
- Seamless automatic transitions between episodes - sit back and enjoy
- Gorgeous pause screens between episodes with show artwork
- Robust fallback system ensures backdrops always load (TMDB -> Fanart cache -> Theme)

[COLOR cyan]How to use:[/COLOR] Navigate to any TV show episode and select "TV Evening" from the context menu.
Add multiple episodes to your playlist and let The Crew handle the rest!

[COLOR orange]TV Evening - Technical Fixes:[/COLOR]
- Fixed timing detection to handle resume points correctly (seek detection + stabilization)
- Fixed overlay not appearing during source scraping
- Fixed backdrop loading failures (database schema migration + TMDB CDN update)
- Fixed overlay staying on screen during playback
- Added session validation to prevent false playback starts
- Migrated to new TMDB image CDN (image.tmdb.org) with automatic URL migration
- Implemented 3-tier backdrop fallback for maximum reliability

[COLOR lime]PERFORMANCE IMPROVEMENTS:[/COLOR]
- Logging Overhead - 98% reduction! (100,000+ lines -> 1,800 lines)
- Cold Start Time - 90% faster (7,800 lines -> 770 lines, 5-8 seconds faster)
- Source scraping is now 75-83% faster (5-15 seconds instead of 60+ seconds)
- Next Episodes widget loads in 2 seconds instead of 45 seconds (95% faster!)
- Progress counter now shows correct scraper names during search
- Scraping timeout reduced to 15 seconds (most results appear in first 5 seconds)
- Smart widget caching - detects cache warmth, instant loads on warm cache
- 30-day TMDB artwork caching for faster navigation
- Reduced disk I/O with optimized logging and caching strategies

[COLOR lime]ARCHITECTURE & CODE QUALITY:[/COLOR]
- BaseScraper Architecture - Unified base class for all ~34 crew scrapers
- TMDBMixin Base Class - Eliminated ~150 lines of duplicate code
- Modern Python 3 patterns throughout (no more Python 2 compatibility code)
- BeautifulSoup4 HTML parser added for complex website scraping
- 113 Regex patterns fixed with raw string literals (r'') for reliability
- Title matching regex modernized for better scraper filename matching
- Thread pool optimization - prevented potential crashes from exhaustion
- Removed dead code: tvmaze.py, dom_parser2.py, legacy scrapers, IMDB lists
- Sports resolver modernization with graceful crypto degradation

[COLOR orange]OTHER FIXES:[/COLOR]
- Pirate Bay sources now return successfully

- Episodes widget not updating after watching episodes
