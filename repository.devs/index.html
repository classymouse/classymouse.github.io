The Crew Dev Repository

Development repository for The Crew side project.

Kodi source (File Manager + repository index): https://classymouse.github.io/repository.devs/

Clean install: Clean Kodi? Update repositories, then install bs4, SimpleJSON, and InputStream Helper from the built-in Kodi Add-on repository before module/plugin. ResolveURL comes from Gujal (bundled in this repo).

One URL only — do not use raw.githubusercontent.com (directories return HTTP 400).
