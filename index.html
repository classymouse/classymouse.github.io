🔬 What is this repository?

This is the alpha / development repository used during pre-release testing of The Crew. It was the staging area for builds before they were promoted to stable.

The 3.0.0 release is not hosted here. Future development builds (3.0.x, 3.1.x, …) will appear here first, before reaching the official repo. This is intentionally bleeding-edge and may be broken at any given time.

If you installed The Crew from this address, please switch to the official repository at https://team-crew.github.io to receive stable updates going forward.

⚠️ This repo is not for regular users

Alpha builds may be incomplete, unstable, or temporarily absent between releases. Use the official repository at https://team-crew.github.io for everyday use.

🔧 Alpha install instructions (developers only)

Only use this if you want to test pre-release builds. For normal use, the official repo above is the right place.

  1. In Kodi File Manager, add source: https://classymouse.github.io Name it "crew-alpha" and click OK
  2. Go to: Settings → Add-ons → Install from zip file
  3. Navigate to the source and install: repository.thecrew.alpha/repository.thecrew.alpha-1.0.10.zip
  4. Then go to: Settings → Add-ons → Install from repository → The Crew Alpha Repository
