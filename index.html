Regular users: install from the official repository above. Testers: the current module 3.0.9.7 / plugin 3.0.11 / artwork 3.1.0 packages are live here now — update via Kodi if you already use this alpha source.

🔧 Alpha install instructions (testers)

Only use this if you are testing pre-release builds. Everyone else should use the official repo in the green banner above.

  1. In Kodi File Manager, add source: https://classymouse.github.io Name it "crew-alpha" and click OK
  2. Go to: Settings → Add-ons → Install from zip file
  3. Navigate to the source and install: repository.thecrew.alpha/repository.thecrew.alpha-1.0.12.zip
  4. Then go to: Settings → Add-ons → Install from repository → The Crew Alpha Repository
