🔒 What's New in v2.6.24 — The 'Race Condition Fix' Release

  • 🚨 CRITICAL: Trakt authentication race condition fixed — Eliminated token expiration bug that occurred when multiple Kodi reboots with widgets were performed. Startup maintenance and widget loads no longer compete for token refresh, preventing Trakt from invalidating both tokens. Verified stable across 15+ consecutive reboots.
  • 🗑️ Cache clearing now works properly — Fixed source_cache table not being cleared with "Clear All Cache", causing rescraped content to use stale cached sources.
  • ⚡ Rate limit handler fixed — Trakt 429 rate limit response now correctly reads Retry-After header from response instead of request.
  • 💾 SQLite VACUUM fixes — All cache databases now properly VACUUM outside transactions, eliminating silent failures.

🤫 What's New in v2.6.23 — The 'Quiet Please' Release

  • 🔕 Silent background Trakt sync — Scheduled Trakt syncs (every few hours) no longer show a 'Syncing with Trakt Finished' popup. The dialog still appears for manual syncs and at startup if silent.boot is off.
  • 🔕 Silent OpenSubtitles skip — If you haven't configured OpenSubtitles credentials or API key, the addon now silently skips instead of popping an info dialog every time.

🛡️ What's New in v2.6.22 — The 'Safety Net' Release

  • 🔄 CDN resilience for live sports — Background service now silently refreshes a local disk copy of crewstreamer, crewschedule and crewreplays every 15 minutes. If CDN goes down during a live game, users keep up to 15 minutes of working streams instead of an immediate error. CDN is still always fetched fresh on every user request when reachable.
  • 🧹 Cleanup — Removed legacy site.py compatibility shim and debridapis.py.old leftover.

What's New in v2.6.21 — The 'No More Ghosts' Release

What's New in v2.6.16 — The 'Remember Where We Left Off' Release

  • 💾 Resume now works — Fixed bookmarks/resume points never being saved. The playback monitor was waiting for a callback that Kodi only delivers on the main thread, so your position was always discarded. Now uses a polling loop that works from any thread.
  • 📉 Real-Debrid 451/429 cascade fixed — DMCA-blocked sources (451) no longer trigger a rate-limit storm that kills all remaining sources. Backoff window reduced from 15s to 3s after measuring RD's actual recovery time (~2.2s).
  • ⚡ No more wasted sources — Sources hitting an active RD backoff now wait out the remainder and proceed, instead of being immediately discarded.
  • 🏷️ Better source labels — Debrid service now appears before quality (e.g. RD | 1080p). Fixed missing debrid label in multiline mode.
  • 🔗 AllDebrid & Premiumize overhaul — Updated to current API versions, fixed pack resolution crashes, added instant availability pre-checks to eliminate redundant API calls.
  • 📦 Pack source fixes — Fixed wrong episode playing from Torrentio pack sources; removed broken RD pre-check that was rejecting valid torrents.

📥 Installation Instructions

Method 1: Direct Repository Source (Recommended)

  1. In Kodi File Manager, add source:
    https://classymouse.github.io/repository.thecrew.alpha/
    Name it "crew-beta" and click OK
  2. Go to: Settings → Add-ons → Install from repository → The Crew Alpha Repository
  3. Install the addons you want to test

Method 2: Repository ZIP Download

  1. Download the repository installer:
    https://classymouse.github.io/repository.thecrew.alpha/repository.thecrew.alpha-1.0.10.zip
    Download Repository Installer
  2. In Kodi, go to: Settings → Add-ons → Install from zip file
  3. Navigate to the downloaded file and install repository.thecrew.alpha-1.0.10.zip
  4. Wait for the "The Crew Alpha Repository Add-on installed" notification
  5. Go to: Settings → Add-ons → Install from repository → The Crew Alpha Repository
  6. Install the addons you want to test
