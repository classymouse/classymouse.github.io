What's New in v2.6.0 — The 'No More Spaghetti' Release

  • ⚡ Smarter scraping — Scrapers that are consistently slow are automatically skipped, so results come back faster.
  • 🔔 Debrid status alerts — When Real-Debrid or AllDebrid is unreachable, you'll now see a friendly notification instead of a silent failure.
  • 🎬 No more interruptions — Fixed popups and dialogs appearing while a video is already playing.
  • 📺 Continue Watching improvements — More reliable tracking; clear resume now actually clears correctly.
  • 🏈 Sports schedule fix — Sports menus no longer crash when no events are currently scheduled.
  • 🔒 Adult PIN recovery — Forgotten PIN? The admin recovery key is now properly secured.
  • 🗑️ IPTV removed — IPTV sources have been removed to keep things clean and focused.
  • 🚀 Faster startup & smoother navigation — Several under-the-hood improvements make the add-on feel snappier overall.

What's New in v2.5.10 — Real-Debrid Token Auto-Refresh

  • 🔑 RD Token Auto-Refresh - Fixed: when the Real-Debrid OAuth access token expires, every pack resolution API call returned 401 Unauthorized and no TV show episode could be played. The resolver now automatically refreshes the expired token using the stored refresh token + client credentials, then retries — no manual re-authentication required.

What's New in v2.5.9 - Xbox One Fix

  • 🎮 Xbox One / UWP Fix - Fixed completely broken HTTPS on Xbox One (Kodi UWP build): ssl._create_unverified_context() is restricted in the UWP sandbox, causing all scrapers and debrid APIs to silently fail. Now uses the UWP-compatible create_default_context() + CERT_NONE path on Xbox.

What's New in v2.5.8 / v2.5.4 - The 'Quick Draw' Release

  • ⚡ RD Pack Pre-Check - Real-Debrid pack resolution now pre-checks instantAvailability before adding the magnet — uncached packs are skipped in ~100ms instead of 3-5 seconds each, dramatically speeding up source selection.
  • ⚡ RD Episode Verification - Pre-check also confirms the specific episode exists in a cached variant, fixing false positives where a torrent was marked cached but the target episode wasn't actually available.
  • 🔧 TV Show Artwork Fix - Fixed worker range bug that caused only every 40th show to get artwork fetched — all shows now get clearlogo/clearart correctly.
  • 🔧 clearlogo/clearart Fix - Artwork fetching now happens unconditionally, no longer blocked by the hq_artwork guard.
  • 🔧 Next Episodes Boot Fix - Fixed widget showing empty after cache clear on boot; added retry-once-after-3s for transient network failures at Kodi startup.
  • 🔧 Missing Language String - Added lang string #32500 'No results found' that was causing a blank infoDialog on empty episode lists.

What's New in v2.5.7 / v2.5.3 - The 'Water Break' Release

  • 🔧 cdnImport Path Fix - Resolved module loading failures when Kodi is launched from certain working directories.
  • 🔧 Local Override Fix - Fixed NameError and accidental deletion bug when using local module overrides.
  • 🔧 Trakt Progress Fix - Episode watch progress now correctly matches by show + season/episode identifiers instead of episode imdb only.
  • 🔧 Trakt Delete Progress Fix - Fixed showimdb lookup when deleting episode progress.
  • 🔧 UpNext Prefetch Guard - Prevented crash when secondary episode is not yet available during prefetch.
  • ⭐ UpNext End Seconds - New setting to configure how many seconds before episode end UpNext dialog appears.
  • 🏗️ CrewService Module - Background service logic extracted to dedicated module for cleaner architecture.

📥 Installation Instructions

Method 1: Direct Repository Source (Recommended)

  1. In Kodi File Manager, add source:
    https://classymouse.github.io/repository.thecrew.alpha/
    Name it "crew-beta" and click OK
  2. Go to: Settings → Add-ons → Install from repository → The Crew Alpha Repository
  3. Install the addons you want to test

Method 2: Repository ZIP Download

  1. Download the repository installer:
    https://classymouse.github.io/repository.thecrew.alpha/repository.thecrew.alpha-1.0.10.zip
    Download Repository Installer
  2. In Kodi, go to: Settings → Add-ons → Install from zip file
  3. Navigate to the downloaded file and install repository.thecrew.alpha-1.0.10.zip
  4. Wait for the "The Crew Alpha Repository Add-on installed" notification
  5. Go to: Settings → Add-ons → Install from repository → The Crew Alpha Repository
  6. Install the addons you want to test

Step 1: Create Orion Account

  1. Visit https://orionoid.com and create a free account
  2. After registration, log in to your account
  3. Go to the Settings → Account section
  4. Copy your API Key (keep this safe!)

Step 2: Configure in The Crew

  1. In Kodi, go to The Crew → Tools → Orion Settings
  2. Enter your Orion API Key
  3. Enable Orion integration
  4. Configure your preferred filters (quality, size, providers, etc.)
  5. Save settings and enjoy enhanced scraping!
